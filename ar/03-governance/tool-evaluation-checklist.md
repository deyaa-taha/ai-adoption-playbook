# قائمة تقييم أدوات الذكاء الاصطناعي

> استخدمها قبل إضافة أي أداة أو ميزة ذكاء اصطناعي إلى القائمة المعتمدة.

**الأداة:** ____________ **المورّد:** ____________ **مقدّم الطلب:** ____________ **التاريخ:** ________

## 1. الملاءمة للأعمال
- [ ] حالة استخدام ومالك واضحان
- [ ] لا تكرّر أداة معتمدة مسبقًا
- [ ] تقدير عدد المستخدمين والحجم الشهري

## 2. حماية البيانات
- [ ] المورّد **لا** يدرّب نماذجه على بياناتنا (مؤكد تعاقديًا)
- [ ] مدة الاحتفاظ بالبيانات معروفة ومقبولة
- [ ] موقع تخزين البيانات / المنطقة معروف ومقبول
- [ ] التشفير أثناء النقل وأثناء التخزين
- [ ] أعلى فئة بيانات مسموح بها: عامة / داخلية / سرّية / مقيّدة

## 3. الأمن والوصول
- [ ] تكامل الدخول الموحّد (SSO) / هوية المؤسسة
- [ ] صلاحيات حسب الدور وأدوات تحكم إدارية
- [ ] سجلات تدقيق متاحة
- [ ] مراجعة الشهادات الأمنية (مثل SOC 2 وISO 27001)
- [ ] دراسة مخاطر حقن الأوامر (Prompt Injection) وتسريب البيانات في الوكلاء واستخدام الأدوات

## 4. الجودة
- [ ] اختُبرت على أكثر من 20 مثالًا حقيقيًا (منقّى) من مجالنا
- [ ] تعمل بلغاتنا (بما في ذلك اللغات التي تُكتب من اليمين لليسار عند الحاجة)
- [ ] سلوك الأخطاء / الهلوسة مقبول لحالة الاستخدام

## 5. التكلفة والتشغيل
- [ ] نموذج التسعير مفهوم (لكل مستخدم / لكل Token / لكل استدعاء)
- [ ] مالك الميزانية وسقف شهري محددان
- [ ] إمكانية مراقبة الاستخدام والتكلفة
- [ ] خطة خروج: تصدير البيانات وبديل للاستبدال
