# 07 · القياس — مؤشرات الأداء والعائد على الاستثمار

> الهدف: إثبات القيمة بأرقام تثق بها الإدارة — وتحديد ما يجب توسيعه أو إيقافه.

## 1. مؤشرات الأداء حسب المستوى

| المستوى | المؤشر | طريقة القياس |
|---|---|---|
| **حالة الاستخدام** | الوقت الموفَّر لكل معاملة | خط الأساس مقابل توقيت التجربة على عيّنة |
| | الحجم المعالَج | سجلات النظام |
| | الدقة / نسبة الخطأ | مراجعة عيّنة مقابل الحقيقة المرجعية |
| | نسبة المراجعة اليدوية | % العناصر تحت حدّ الثقة |
| | التكلفة لكل معاملة | تكلفة البوابة ÷ عدد المعاملات |
| **البرنامج** | حالات الاستخدام في الإنتاج | قائمة دورة الحياة |
| | الساعات الموفَّرة شهريًا (الإجمالي) | المجموع عبر حالات الاستخدام |
| | المستخدمون النشطون للأدوات المعتمدة | لوحات إدارة الأدوات |
| | الوقت من الفكرة إلى الإنتاج | تواريخ دورة الحياة |
| **الأشخاص** | الموظفون المدرَّبون (حسب المسار) | سجلات التدريب |
| | الرضا / الفائدة المُدرَكة | استبيان ربعي قصير |
| **المخاطر** | حوادث مخالفة السياسة | سجل الحوادث |
| | اتجاه الاستخدام الخفي للذكاء الاصطناعي | إشارات الشبكة / CASB، استبيانات |

## 2. معادلة العائد على الاستثمار

```text
الفائدة الشهرية   = الساعات الموفَّرة × كلفة الساعة الكاملة
                  + كلفة الأخطاء التي تم تجنّبها
                  + مكاسب أخرى قابلة للقياس (اتفاقيات خدمة أسرع، إيرادات، إلخ)

التكلفة الشهرية   = التراخيص + استخدام النماذج + المنصّة/الاستضافة
                  + جهد الدعم والصيانة

العائد (12 شهرًا) = (12 × الفائدة الشهرية − كلفة البناء لمرة واحدة − 12 × التكلفة الشهرية)
                    ÷ (كلفة البناء لمرة واحدة + 12 × التكلفة الشهرية)
```

**كن متحفظًا.** احتسب فقط الوقت الذي يُعاد توجيهه فعلًا إلى أعمال أخرى، واعرض افتراضاتك.

## 3. مثال محسوب (توضيحي)

| البند | القيمة |
|---|---|
| الرسائل المصنّفة شهريًا | 6,000 |
| الوقت الموفَّر لكل رسالة | 1.5 دقيقة |
| الساعات الموفَّرة شهريًا | 150 |
| كلفة الساعة الكاملة | ‎$40 |
| **الفائدة الشهرية** | **‎$6,000** |
| تكلفة النماذج والمنصّة شهريًا | ‎$400 |
| جهد الدعم شهريًا | ‎$600 |
| **التكلفة الشهرية** | **‎$1,000** |
| كلفة البناء لمرة واحدة | ‎$15,000 |
| **العائد خلال 12 شهرًا** | (72,000 − 15,000 − 12,000) ÷ (15,000 + 12,000) = **167%** |

## 4. تقرير الإدارة العليا (ربعي، صفحة واحدة)

1. **العنوان الرئيسي:** الساعات الموفَّرة، حالات الاستخدام الحيّة، العائد حتى تاريخه
2. **النجاحات:** 2–3 قصص قصيرة بالأرقام مع اقتباس من مستخدم
3. **قيد التنفيذ:** ما هو في مرحلة التجربة، وما التالي
4. **المخاطر والحوادث:** ماذا حدث، وما الذي تغيّر
5. **الطلبات:** ميزانية، أشخاص، قرارات مطلوبة
